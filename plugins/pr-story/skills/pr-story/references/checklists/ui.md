# UI

- **States.** Loading, empty, error, and partial data: what does each look like? Show them.
- **Before and after.** Screenshots or a short recording, at desktop and phone widths when
  layout changed.
- **Accessibility.** Keyboard only, focus order, labels on controls, contrast, and screen-reader
  text for icon buttons.
- **Optimistic updates.** If the UI updates before the server confirms, what happens when the
  server says no?
- **Copy.** Are new strings clear, consistent with the rest of the app, and translatable if the
  app is localized?
