# Language plugin template

1. `cp -r plugins/lang-template plugins/lang-python` (or java, kotlin, swift...)
2. Replace `LANG` and `EXT` everywhere, rename `skills/LANG`, and fill in the TODOs.
3. Add an entry to `.claude-plugin/marketplace.json`.
4. Run `scripts/validate.sh`.

This template is intentionally not listed in the marketplace.
